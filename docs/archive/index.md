# Archivo histórico

Conserva decisiones y evidencias fechadas que explican la evolución del proyecto. Sus afirmaciones de funciones pendientes, límites antiguos, datos de planificación y conteos de pruebas pertenecen a esa etapa. Los enlaces se actualizan para permitir consulta; no se convierten retrospectivamente en resultados nuevos.

Las guías vigentes están en el [índice principal](../index.md). La matriz académica y la evidencia final siguen accesibles desde allí.
